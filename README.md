# Crypto Signal Terminal

本地优先的加密货币合约机会终端。它只展示能影响交易决策的公开市场证据：多周期趋势、主动成交、盘口失衡、持仓量变化、波动压缩、跨交易所价格确认，以及聪明钱候选。

## v0.5.0 已实现

- Bitget 默认绿涨红跌：K 线、影线、量能与订单目标统一采用绿涨红跌；坐标轴、十字光标均按北京时间显示，并在实时更新后贴齐最新 K 线。
- 多周期与指标：5m / 15m / 1h / 4h；主图可切 MA20、EMA12、BOLL20，副图可切 VOL、RSI14、MACD。
- 热门山寨雷达：聚合 Binance、Bybit、OKX、Bitget 的公开永续合约 24 小时成交额排名，以跨交易所排名与覆盖度选出 Top10 山寨币；BTC、ETH 维持主流趋势跟踪。

## v0.4.0 已实现

- 动态证据融合：基于市场状态动态融合多空趋势、衍生品、订单流、异常与跨所确认，估计 `P(TP before SL)` 与计入费用/滑点后的期望值；不满足门槛时只保留观察，不生成订单。
- 实时性：行情 HTTP 连接复用、6 路受控并发、5 秒扫描与 5 秒客户端断线兜底；K 线按北京时间（UTC+8）显示。
- 终端微调：左侧状态点与文字彻底分离、可用分类改为全部/主流/山寨/聪明钱，K 线与量能统一为蓝涨红跌配色。

## v0.3.0 已实现

- 纯交易终端框架：固定顶部状态、左侧机会流、中心信号画布、右侧模拟订单；图表手势不再被页面滚动劫持。
- 流畅 K 线：Lightweight Charts 单实例生命周期、按最新 K 线增量更新、品种切换时才重置视图；滚轮缩放、拖拽平移与触控缩放直接交给图表。
- 机会与风控：BTC/ETH 多周期趋势、山寨临界雷达、合约订单流聪明钱候选；只有结构完整、数据健康且未过期时才能准备模拟订单。
- 本地安全：只监听 `127.0.0.1`；Dune 凭据存放于系统钥匙串；本地 SQLite 仅保留模拟订单历史，不接收交易所 API Key，也不自动下单。

默认桌面应用使用真实公开行情。断网、行情降级或尚无可验证 K 线时保持空态，不用模拟走势代替真实市场。Bybit 提供合约价格、5m K 线、盘口、主动成交和 OI；OKX 用于跨交易所价格确认。Dune 查询适配器已预留，尚未进入后台调度。

## 本地开发

```bash
cd /Users/a0000/crypto-signal-terminal-v03
./scripts/bootstrap.sh
./scripts/run-demo.sh
```

上面的脚本显式启动可复现演示模式；正常桌面应用不会自动载入演示机会。

另一个终端启动界面：

```bash
cd /Users/a0000/crypto-signal-terminal-v03/desktop
pnpm dev
```

## 构建 macOS 应用

```bash
cd /Users/a0000/crypto-signal-terminal-v03
./scripts/build-sidecar.sh
cd desktop
pnpm tauri build
```

构建产物位于 `desktop/src-tauri/target/release/bundle/`。当前构建目标为 Apple Silicon macOS，使用本机临时签名；未经 Apple Developer ID 公证，适合本机安装测试。

## 风险边界

这是决策支持软件，不保证预测准确。交易建议有数据时效和滑点上限；数据陈旧、结构不完整或盈亏比不足时会拒绝给单。真实资金执行必须由使用者确认；高杠杆可能迅速造成全部保证金损失。
